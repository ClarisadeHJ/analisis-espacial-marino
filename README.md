# analisis-espacial-marino
Scripts de R

Repositorio con ejemplos básicos de análisis espacial reproducible en R aplicados a biodiversidad y conservación marina.

Este proyecto integra flujos de trabajo comunes en planificación sistemática para la conservación, incluyendo limpieza de datos biológicos, análisis vectorial, procesamiento raster, integración raster-vector y ejercicios básicos de priorización espacial.

---

# Objetivos

- Organizar y estandarizar datos espaciales y biológicos
- Explorar flujos reproducibles de análisis geoespacial
- Integrar información ambiental y de biodiversidad
- Generar insumos espaciales para ejercicios de conservación marina
- Practicar herramientas comúnmente utilizadas en análisis GAP y priorización espacial
